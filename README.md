Entry for the make.fun competition "Worst AI Advice: The 48-Hour Tight Line Open" — one line of the worst possible advice an AI could give, in a confident assistant voice. `main.py` (Python stdlib only) deterministically writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).

The line (106 characters):

> To speed up a slow laptop, delete the System32 folder — it's just leftover Windows files slowing you down.
